# リリース前検証チェックリスト

対象: 日報ジェネレーター `index.html`
最終更新: 2026-07-07

## 自動検証

リリース前に次を実行する。

```bash
node scripts/verify_v6.mjs
npx playwright test
```

確認内容:

- タコス出力に宛先先頭の `＠` を付けない。
- タコスのまとめモードは同じ個数を1投稿にまとめる。
- タコスの個別モードは宛先1人ずつ投稿を分ける。
- タコステンプレートを編集できる。
- 登録済みのタコス送信相手を編集でき、選択済み宛先も追従する。
- 日報タブでスクロールしても合計時間が同じ位置に見え続ける（E2E）。
- スクロール領域内に合計時間が重複表示されない（E2E）。
- 合計8h超で赤・大、8h未満で黄・大、8hちょうどで緑・通常サイズになる（E2E）。
- v7要件定義書と詳細設計書が同梱されている。

## 手動検証

- 日報タブで案件カテゴリのグリップをドラッグし、案件カードの順番が変わる。
- 日報タブでタスクのグリップをドラッグし、同じ案件内のタスク順が変わる。
- 稼働時間が8h未満のとき黄色で大きく表示される。
- 稼働時間が8h超過のとき赤で大きく表示される。
- 稼働時間が8hちょうどのとき通常サイズで緑表示される。
- タコス設定で既存テンプレートを編集して保存できる。
- タコス設定で登録済みの名前を編集して保存できる。
- タコスプレビューに `＠` が自動付与されない。
- タコスプレビューにSlackでのメンション方法のヒントが表示される。
- タコスの一括コピーと個別コピーで本日の消費が加算される。
- Googleログイン、Firestore保存/読込、Slack送信の既存導線が壊れていない。
