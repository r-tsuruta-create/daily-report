# 日報ジェネレーター 詳細設計書

対象リポジトリ: `r-tsuruta-create/daily-report`

本書は 2026-06-25 時点の実装済み `index.html` に合わせた詳細設計である。

## 0. 統合方針

- `index.html` はバニラ単一HTML。
- 見た目と画面ロジックは実装版HTMLを土台にする。
- 認証、Firestore同期、Slack送信は旧 `index.html` の関数シグネチャを維持して移植する。
- Firestoreは新構造として保存し、旧データは引き継がない。
- バンドル生成物や読みにくいエスケープ済みテンプレートは使わない。

## 1. 主要データ構造

### 1-1. `state`

```js
state = {
  tab: 'report' | 'tacos' | 'settings',
  theme: 'light' | 'dark',
  tone: '青' | '藍' | '緑' | '橙' | '桃' | '紫',
  day: 'today' | 'tomorrow',
  greeting: string,
  today: Category[],
  tomorrow: Category[],
  presets: string[],
  contacts: TacoContact[],
  blocks: TacoBlock[],
  templates: TacoTemplate[],
  tacoMode: 'merge' | 'split',
  accumulated: number,
  usageDate: string,
  webhook: string
}
```

### 1-2. 日報

```js
Category = {
  id: number,
  category: string,
  tasks: Task[]
}

Task = {
  id: number,
  hours: number,
  name: string
}
```

- `today` は退勤報告タブの入力。
- `tomorrow` は朝会報告タブの入力。
- 出力では案件名に `＜＞` を付ける。

### 1-3. タコス

```js
TacoContact = {
  id: number,
  name: string,
  freq: number
}

TacoBlock = {
  id: number,
  recipients: string[],
  count: number,
  body: string
}

TacoTemplate = {
  id: string,
  label: string,
  body: string
}
```

- 宛先初期値は空。
- 実名やSlackユーザーIDはコードに書かない。

## 2. 画面設計

### 2-1. 固定レイアウト

- `.app` は `height: 100vh; height: 100dvh;`。
- `.header` は `position: fixed` で上部固定。
- `.subheader` は日報/タコス用の固定補助ヘッダー。
- `.nav` は `position: fixed` で下部固定。
- `.scroll` は絶対配置のスクロール領域。
- `.scroll` は下部ナビ分の padding-bottom を持つ。
- タブごとに `.app[data-tab="..."] .scroll` の `top` を切り替える。

### 2-2. 日報タブ

- `viewSubheader()` で退勤報告/朝会報告セグメントとワンタッチコピーを表示する。
- ワンタッチコピーボタンは、現在開いている画面の反対側の報告をコピーする。
  - `state.day === 'today'`: `朝会報告の内容をコピー` と表示し、`outputBlocks().block3` をコピーする。
  - `state.day === 'tomorrow'`: `退勤報告の内容をコピー` と表示し、`outputBlocks().block1` をコピーする。
- `viewReport()` は `groupsOf()` の結果を編集対象として表示する。

### 2-3. タコスタブ

- `viewSubheader()` で本日の消費メーターを表示する。
- `viewTacos()` の先頭には余分な「タコスを贈る」見出しブロックを置かない。
- 画面はすぐ宛先+文面ブロックから始まる。
- 出力プレビュー内で `merge` / `split` を切り替える。
- コピー時に `accumulated` を加算する。
- 設定画面には `accumulated` の手動調整欄を置かない。

### 2-4. 設定タブ

- 表示、Slack連携、Googleログイン、タコス送信相手、日報プリセット、タコステンプレートを表示する。
- Googleログインカードは `currentUser` を表示する。
- ログインボタンは `googleLogin()`、ログアウトボタンは `googleLogout()` に接続する。
- 本日のタコス消費欄は表示しない。

## 3. 関数設計

### 3-1. 出力

```js
formatDay(groups)
outputBlocks()
```

- `formatDay(groups)` は案件カテゴリごとに `＜案件＞` と `X.Xh｜タスク名` を作る。
- `outputBlocks()` は3まとまりを返す。

```js
{
  block1: '退勤報告',
  block2: '今日やったこと',
  block3: '明日やること'
}
```

### 3-2. タコス投稿生成

```js
tacoPosts()
```

- `merge`: 同じ個数ごとにまとめる。
- `split`: 宛先1人ごとに分ける。
- 戻り値には `num`、`count`、`people`、`consume`、`text` を含める。

### 3-3. 保存

```js
serializableState()
persistLocal()
persist(immediate = false)
```

- localStorage キーは `daily_report_state_v5`。
- Webhook URL は `webhook_url` にも保存する。
- テーマは `theme` にも保存する。
- UIだけの一時状態はFirestoreへ保存しない。

## 4. Firebase / Slack 移植

旧 `index.html` から次の関数名を維持して移植する。

```js
googleLogin()
googleLogout()
userDocRef()
loadFromFirestore()
saveToFirestore()
debouncedFirestoreSave()
postToSlack(text)
```

### 4-1. Firebase初期化

- Firebase compat CDNを使う。
- `firebase.initializeApp(firebaseConfig)` を使う。
- `auth = firebase.auth()`。
- `db = firebase.firestore()`。
- `auth.onAuthStateChanged` を初期化時に登録する。
- `setPersistence` は呼ばない。

### 4-2. Firestore

- 保存先は `users/{uid}`。
- `loadFromFirestore()` はユーザー文書を一括取得する。
- `saveToFirestore()` は `{ merge: true }` で保存する。
- `saving` / `saveQueued` で多重保存を防ぐ。
- `debouncedFirestoreSave()` は1500msの遅延保存。

保存キー:

- `reportWork`
- `reportPresets`
- `tacoContacts`
- `tacoTemplates`
- `tacoBlocks`
- `tacoUsage`
- `tacoMode`
- `webhookUrl`
- `theme`
- `accentColor`
- `updatedAt`

### 4-3. Slack

- `postToSlack(text)` は `fetch`、`mode: 'no-cors'`、`payload=` 形式を使う。
- 日報のSlack送信は `block1`、`block2`、`block3` を順に送る。
- タコスはSlack送信しない。

## 5. 実装済み修正項目

### 5-1. 固定ヘッダー/固定下ナビ

- `.header` と `.nav` を `position: fixed`。
- `.subheader` も固定。
- `.scroll` に `padding-bottom` を確保。
- `100dvh` を使用。

### 5-2. ワンタッチコピー

- セグメント直下に表示。
- 退勤報告タブでは `朝会報告の内容をコピー` と表示し、`block3` をコピーする。
- 朝会報告タブでは `退勤報告の内容をコピー` と表示し、`block1` をコピーする。

### 5-3. コピー内容の対応

- 退勤報告タブ = `today`。
- 朝会報告タブ = `tomorrow`。
- `outputBlocks()` の `block1` / `block2` は `today`、`block3` は `tomorrow`。

### 5-4. ログイン保持

- `setPersistence` は使わない。
- `auth.onAuthStateChanged` で `currentUser` を復元する。
- ログイン済みなら `loadFromFirestore()` を呼ぶ。

### 5-5. タコス画面

- 余分な「タコスを贈る」見出しブロックを削除。
- 宛先+文面ブロックから始める。
- 本日の消費メーターはタコス固定ヘッダーに表示。
- 設定タブの「本日のタコス消費」欄は削除。
